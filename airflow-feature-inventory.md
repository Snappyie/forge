# Apache Airflow — Categorized Feature Inventory (2.x / 3.x)

Reference data for parity checking. Baseline: Airflow 3.3.x stable; Airflow-2.x-only or version-dependent items are marked inline.
Legend: [core] = fundamental/built-in capability; [extended] = advanced, optional, provider/ecosystem, deployment-specific, or experimental capability.

## 1. DAG Definition & Authoring

- DAGs defined as Python code via `DAG` class, context manager, or plain constructor [core]
- `@dag` decorator that turns a function into a DAG generator [core]
- TaskFlow API `@task` decorator wrapping Python callables as tasks [core]
- `@task_group` decorator for grouped tasks [core]
- DAG identity/metadata fields: `dag_id`, `description`, `owners`, `owner_links`, `tags`, `doc_md`, `default_view`, `orientation`, `dag_display_name` [core]
- DAG-level `default_args` applied to all tasks [core]
- DAG-level `params` declared with `Param` and JSON-schema validation [core]
- Runtime DAG configuration via `dag_run.conf` passed to templated fields [core]
- Jinja templating of `template_fields` at task runtime [core]
- Built-in template macros (`ds`, `ts`, `logical_date`, `data_interval_start/end`, `ti`, `dag_run`, `params`, `var`, `conn`) [core]
- User-defined macros (`user_defined_macros`) and filters (`user_defined_filters`) [extended]
- `template_searchpath` and custom Jinja environment kwargs [extended]

- DAG/task/task-group documentation (`doc_md`, `doc_json`, `doc_yaml`, `doc_rst`, TaskGroup `tooltip`) rendered in UI [extended]
- Dynamic DAG generation programmatically from config/data at parse time [core]
- DAG code packaging/import from installed Python packages and PYTHONPATH entries [core]
- `.airflowignore` file to exclude paths from DAG parsing [core]
- DAG import error surfacing (`airflow dags list-import-errors`, import-error UI, import-error listener events) [core]
- DAG dependency view over asset/dataset relationships [extended]
- DAG cycle detection and DAG validation helpers (`dag_cycle_tester`, `DagBag`) [extended]
- DAG test tooling: `airflow dags test`, `airflow tasks test`, in-process `Dag.test()`, simulated DAG run (3.2+) [core]
- DAG compatibility/upgrade checks via `ruff` AIR rules and `airflow dags reserialize` [extended]
- Static type checking support for DAGs [extended]
