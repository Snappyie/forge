# Contributing

Read `docs/18-open-source-governance.md` and `docs/23-documentation-standard.md` first.

Before opening a PR:
1. Run formatting.
2. Run Clippy.
3. Run unit/integration tests.
4. Run security/license checks.
5. Update documentation.
6. Update acceptance tests for behavior changes.
7. Add an ADR/RFC when required.

Keep PRs focused and explain operational and security consequences.
